# fim — File Integrity Monitor

Консольная утилита контроля целостности файлов на C++11. Строит базу SHA-256 хешей каталога и при повторном запуске показывает изменённые, новые и удалённые файлы.

- Собственная реализация SHA-256 (без сторонних библиотек), проверена на векторах NIST
- Потоковое чтение файлов блоками по 64 КиБ
- Многопоточное хеширование (`std::thread`, `std::atomic`)
- RAII для системных ресурсов (`unique_ptr` с собственным deleter для `DIR*`)
- Кроссплатформенно: Linux/macOS (POSIX) и Windows (WinAPI)

## Сборка

    cmake -S . -B build
    cmake --build build
    ctest --test-dir build        # или ./build/test_sha256

Без CMake (Linux/macOS):

    g++ -std=c++11 -O2 -pthread src/*.cpp -o fim

## Использование

    fim init  <каталог> <база> [-j N]    # создать базу
    fim check <каталог> <база> [-j N]    # проверить

Коды возврата: `0` — без изменений, `1` — есть различия, `2` — ошибка.
Пример вывода `check`:

    MODIFIED  a.txt
    NEW       sub/new.txt
    DELETED   c.txt

## Ограничения

- Символические ссылки пропускаются.
- Имена файлов с символом перевода строки не поддерживаются форматом базы.
- База не защищена от подмены: храните её отдельно от проверяемого каталога.
